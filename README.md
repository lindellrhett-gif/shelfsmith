# Shelfsmith: public site

The support page, Privacy Policy, Consumer Health Data Privacy Policy, and
Terms for **Shelfsmith**, a shared-pantry app that shows what you can cook with
what you already have.

**Live site:** <https://lindellrhett-gif.github.io/shelfsmith/site/>

**About the app:** see the [project page](https://lindellrhett-gif.github.io/shelfsmith.html)
on my portfolio for features, architecture, and how it works.

Served by GitHub Pages. The pages are plain HTML and CSS in [`site/`](site).
